About

A pixel-art secure web gateway site on a golden-ratio type and spacing system: a dusk-sky hero, value proposition, decrypting feature board, a sticky 3D dashboard riding three sections, how it works with a request simulator, case studies, pricing with a seat calculator, a get-started wizard and a random landing-page generator.

Designed for

  • A pixel-art / 8-bit product or game-adjacent landing page with real depth
  • Seeing a sticky, scroll-linked dashboard header driving three sections
  • Pointer-tilt 3D cards, CSS 3D cubes and a radar built from plain transforms
  • Rolling a random, shareable template from a seed and painting the whole site with it
